A security review of the app you ship.

I take the app apart and write down what it actually does: what it asks the device for, what it keeps, and which servers it talks to. Every finding carries the file and the line. The report also names what could not be checked.

What the review covers

  1. Permissions.What the app asks for on the device, and whether each one earns its place.
  2. Storage.What it keeps on the device, in what form, and for how long.
  3. Outbound traffic.Every host it contacts, and what it hands to each one.
  4. Exposure.SQL injection, cross-site scripting, insecure direct object references, server-side request forgery and path traversal, tested against the app as built, not as described.
  5. Evidence.File and line for every finding, the tools and versions used, and an explicit list of what the review did not cover.
